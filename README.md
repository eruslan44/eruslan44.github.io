# Руслан Егоров — личный сайт

Двуязычный адаптивный сайт-визитка. React 19, TypeScript, Vinext и Vite; статическая сборка для GitHub Pages.

## Разработка

Node.js >= 22.13.0.

```sh
npm ci
npm run dev
```

Страницы: `/ru` и `/en`. Корневая страница перенаправляет на `/ru`.

`npm run dev` запускает сервер разработки с автоматическим обновлением при изменении исходников, включая `app/projects.ts`. Используйте адрес, который сервер напечатает в терминале.

Для проверки статической сборки локально:

```sh
npm run build
```

Готовые HTML, CSS и JavaScript находятся в `dist/client`. После редактирования исходников пересоберите сайт. GitHub Pages не запускает серверную часть Vinext.

```sh
npm run build
npm run lint
npx tsc --noEmit
```

## Публикация на GitHub Pages

Сайт публикуется по адресу `https://eruslan44.github.io/` из репозитория `eruslan44/eruslan44.github.io`. Один раз в настройках репозитория выберите **Settings → Pages → Build and deployment → Source → GitHub Actions**. Поле **Custom domain** оставьте пустым.

Workflow `.github/workflows/pages.yml` собирает сайт и публикует `dist/client` при каждом push в `master`. Для ручного запуска используйте **Actions → Publish GitHub Pages → Run workflow**. Workflow проверяет имя репозитория и наличие `index.html`, `ru.html` и `en.html` перед публикацией. Он также создаёт `ru/index.html` и `en/index.html` для прямого открытия языковых страниц и добавляет `.nojekyll`, чтобы GitHub Pages обслуживал каталог `_next`.

## Контент

- `app/content.ts` — тексты обеих языковых версий и опыт работы.
- `app/projects.ts` — массив проектов. Добавьте URL, название и описание на двух языках. Пока массив пуст, отображается сообщение о будущих публикациях.
- `app/profile.tsx` — структура, контакты и метаданные.
- `app/globals.css` — палитра, адаптивная сетка и стили.

Информация об опыте взята из предоставленного резюме от 27 августа 2026 года. Биография дополнена по сообщению владельца. Источник фактов о Пыщуге: https://www.culture.ru/events/2940315/simvol-pyshugskogo-kraya (краеведческий музей «Пыщуганье»). Ссылка также размещена на сайте. Исходный PDF в публичную папку не копируется.

Сгенерированный сторонний каталог `components/ui` и его `hooks/use-mobile.ts` исключены из линтинга: они содержат исходные диагностические ошибки шаблона и в текущем интерфейсе не используются. TypeScript проверяет весь проект.
